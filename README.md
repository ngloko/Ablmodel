Аблитерация модели

Данное руководство предназначено исключительно для изучения внутреннего устройства LLM и методов изменения их поведения в академических или исследовательских целях. Автор не одобряет использование аблитерированных моделей для генерации вредоносного, незаконного или неэтичного контента. Пользователь берёт на себя всю ответственность за применение полученных знаний.
Здесь я написал мини-гайд, как дообучить свою локальную модель с самого начала.
Справедливости ради, проще и быстрее скачать просто аблитерованную модель, однако это даёт возможность самостоятельно настраивать веса и, в общем, настраивать свою модель глубже, чем системный промпт или параметры.
Необходимые инструменты и ссылки для скачивания
- Python — https://www.python.org
- Ollama — https://ollama.com
- PyTorch — https://pytorch.org
- Heretic — https://github.com/p-e-w/heretic
Я опишу процесс на примере Qwen 3 8B, используя платформу Ollama.com и ОС Windows.

1. Установка Ollama и нашей модели
Ну, тут всё просто: переходим на официальный сайт и устанавливаем продукт.
После установки можно работать и с UI, однако я этим не занимался и не могу сказать ничего конкретного.
Поэтому открываем PowerShell и пишем команду:

        ollama serve

Это запустит программу, и мы сможем начать работу.
Далее нам нужно установить нашу локальную модель.
 Для этого пишем:

      ollama run [Модель, которую хотите установить]

Для Qwen 3 8B:
  
      ollama run qwen3:8b

После этого начнётся установка модели и дальнейший её запуск. Вы сможете общаться с моделью, однако она всё ещё будет с цензурой.

Команда для abliterated (не понял, как на русский перевести) модели:
  
      ollama run huihui-ai/qwen3-8b-abliterated

3. Установка инструмента для аблитерации
Тут уже побольше установок. Я использовал Heretic, но, вроде, есть аналоги.
Убедитесь, что у вас установлены Python и PyTorch (желательно с поддержкой CUDA для ускорения на видеокарте NVIDIA).
Команда для установки Heretic:

        pip install heretic-llm

5. Аблитерация

Чтобы не возникало ошибок, лучше запустить PowerShell от имени администратора. Возможно, потребуется отключить антивирус и защиту Windows.

Далее нужно всё-таки запустить то, что мы скачали:
  
  heretic Qwen/Qwen3-4B-Instruct-2507

После команды выше нужно будет долго ждать, так что может показаться, что всё зависло, потому что в таком режиме Heretic не выводит происходящее.

По умолчанию Heretic использует по 400 «хороших» и 400 «плохих» промптов, но это очень долго при не самом хорошем железе. Так что мы воспользуемся инструментарием Heretic, уменьшим количество запросов, попросим выводить результат и отключим графики, чтобы было быстрее:
  
  heretic Qwen/Qwen3-4B-Instruct-2507 --good-prompts.split "train[:50]" --bad-prompts.split "train[:50]" --print-responses --no-plot-residuals

Это уменьшит количество примеров до 50, покажет ответы и отключит генерацию графиков.
Здесь будет снова установка модели с Hugging Face, однако мы можем указать путь до модели, которую установили раньше, и не нужно будет ждать ещё раз.

5. Сохранение модели
В итоге Heretic создаст новую версию вашей модели с изменёнными весами. В зависимости от того, как вы настроили экспорт (или если не настраивали — вас спросят), вы получите один из двух вариантов:
Полная объединённая модель (Merge) — папка с новыми весами, которую можно использовать как обычную модель. Веса уже изменены, и вы можете сразу загружать её в Ollama, LM Studio или через Transformers.
Адаптер LoRA (Adapter) — небольшая папка с файлами, содержащими только изменения весов (дельту). Этот адаптер нужно будет применять поверх оригинальной модели при загрузке. Это экономит место, но требует наличия базовой модели.

6. Импорт модели в Ollama

После сохранения модели скопируйте путь к ней и создайте файл Modelfile со строкой:
  
  FROM [путь к модели]

И сохраните его.
После этого снова заходим в PowerShell и пишем команду:

  ollama create [Название модели] -f ./Modelfile

Это создаст модель, которую нужно запустить:

  ollama run [Название модели]

Ваша модель будет запущена в командной строке в Ollama.

7. Рекомендации и т. д.

Можно подключить UI для Ollama и общаться со своей моделью на localhost, однако там простое использование Docker.
Инструменты, использовавшиеся в работе: Ollama, Heretic, Python.
